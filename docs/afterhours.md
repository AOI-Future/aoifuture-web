# AFTERHOURS

サイト内のリミナルスペース探索ゲームを追加する今回の依頼に合わせた実装。
`/apps/afterhours` が紹介、`/play/afterhours` がゲーム。`src/data/apps.ts` から一覧に掲載。
通常の独立アプリの責任分界は docs/apps.md のまま。このゲームは今回のサイト内実装に限定する。

## 遊び方

- WASD / 上下矢印で移動。左右矢印またはマウスで視点。Shiftで加速。
- タッチは左スティックで移動、画面スワイプで視点。「加速」はトグル。
- 光に近づくと残響を収集。矢印と距離は次の光、または手帳で選んだ場所を示す。
- 8種類の空間を探索する。時間制限・ゲームオーバーはない。
- 「場所を記録」または B で手帳へ。最大8件。一時停止して記録を選ぶと帰路の方角を表示。
- 発見した空間の種類も保存。収集数では景観を変えず、座標ごとの場所の記憶を保つ。
- Esc / PAUSEで停止。タブを離れると入力と音声を停止。
- localStorageに位置・方向・seed・収集数・次の目的地・発見した種類・記録した場所を保存。5秒ごと、収集時、停止時に保存。
- 「新しい空間」は確認後にセーブを置換。保存不可の環境ではセッション中のみ保持。

## 実装

Three.js + Web Audio。ゲームページだけが3Dコードを読み込む。外部画像・音声は使わない。
32mの区画を座標とseedから再生成し、周囲25区画（軽量）/49区画（高画質）だけ保持。
geography.tsが空間の正本。待合室、書架、水盤、吹き抜け、事務室、展示室、配管廊、温室の8種。
32m区画をゆるい地区にまとめ、同種の広い部屋は18mまたは24mの開口で連結する。入口は隣接両側で一致。
部屋には固有アドレス、サイン、固定の目印があり、家具配置の向きにも変化をつける。
柱と壁は中心の通路を塞がない配置。壁との衝突判定あり。ピクセル比は1/1.5まで。
音楽・低音ドローン・足音・収集音はオリジナル合成。開始クリックでAudioContextを作成。
カーペット、タイル、石、コンクリートで足音が変わり、残響量は空間ごとに補間する。
箱形の造形は材質ごとにInstancedMeshへまとめる。区画を捨てる際は固有の看板テクスチャ・インスタンスを解放する。
旧セーブが新しい家具に重なる場合、最も近い通路に位置を補正。発見履歴と手帳は空から開始。
音量、ミュート、軽量描画、任意の視点揺れ。OSの動き軽減を尊重。

## 検証

- `npm run build`
- `npm run check:afterhours`
- `npx vitest run tests/afterhours-world.test.ts`
- `npm run test:afterhours` — desktop / phone / tablet のChromium検証
- スクリーンショット先は `AFTERHOURS_SCREENSHOT_DIR` で上書き可能。

実機iOS Safari / Android、主観的な音質、長時間プレイ時の発熱と電池消費は未確認。
数学的な無限ではなく、必要な範囲を繰り返し生成する方式。極端な座標では浮動小数点精度に限界がある。
2026-09-13のユーザー公開指示に基づき、mainへの反映とVercelの本番デプロイを進める。
Xへの実投稿は対象外。GIFは添付用、OGPは public/og/afterhours.png の静止画を使う。
